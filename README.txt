Taha's Helper Bot — نسخه 25

تغییرات این نسخه:
- قابلیت ویرایش تصویر و دکمه آن کاملاً حذف شد.
- پاسخ‌های دارای ```code``` داخل کادر کد شبیه محیط ChatGPT نمایش داده می‌شوند.
- برای هر کادر کد دکمه «کپی کد» وجود دارد.
- وقتی کاربر صراحتاً درخواست ساخت فایل کند، بدون هیچ دکمه یا گزینه جداگانه، بات فایل را می‌سازد.
- فایل ساخته‌شده با دکمه دانلود در همان پاسخ قابل دریافت است.
- پسوند فایل بر اساس درخواست کاربر (Python/JS/HTML/CSS/JSON/CSV/...) تا حد امکان تشخیص داده می‌شود.
- طراحی اصلی حفظ شده و فقط قابلیت‌های درخواستی جایگزین شده‌اند.

اجرا:
1) pip install flask requests
2) python app.py
3) API Key را در ترمینال وارد کن.
4) برای ساخت تصویر، در صورت نیاز Pollinations Key را در ترمینال وارد کن.
